# Three-minute demo

1. Open WHYBASE and explain: “An answer without a receipt is not an answer.”
2. Ask the upstream-service ownership question. Show tool trace, animated evidence nodes, Cypher, ids, and confidence.
3. Toggle Graph OFF and ask the same question. Show the weaker vector baseline.
4. Switch tenant to Halcyon to demonstrate isolation.
5. Open Alerts and show Sentinel’s BUS_FACTOR alert and human approval action.
6. Open Memory and explain episodic, semantic, and procedural graph memory.
7. Run Arena and narrate the per-mode accuracy comparison.
8. Finish with FalkorDB Browser: two `kb_*` graphs and the connected data model.
